# coolblocks
Эта игра создано искусственным интеллектом незнаю понравится ли она вам или нет

## About the Game
CoolBlocks is a simple shooting game where you aim with a crosshair and click to destroy falling blocks!

## Features
- **Custom Crosshair UI**: A red crosshair that follows your mouse cursor
- **Falling Blocks**: Colorful blocks fall from the top of the screen
- **Score System**: Earn 10 points for each block you shoot
- **Visual Effects**: Explosion effects when blocks are hit

## How to Play
1. Open `index.html` in your web browser
2. Move your mouse to aim with the crosshair
3. Click on blocks to shoot them
4. Try to get the highest score!

## Files
- `index.html` - Main game page
- `style.css` - Game styling and crosshair UI
- `game.js` - Game logic and mechanics
